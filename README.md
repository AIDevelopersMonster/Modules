# Modules

Engineering library of electronic hardware modules.

## Purpose

Identification, documentation, integration and practical
application of electronic modules.

Each module may contain:

- Hardware identification and board revision
- Electrical characteristics and pinout
- Datasheets and technical references
- Connection examples
- Software and drivers
- Practical notes and verified functionality

Documentation grows as modules are used.

## Categories

| Category | Description |
|----------|-------------|
| [Times](Times/) | RTC and electronic time modules |

## Repository structure

Categories contain directories for specific physical modules.

Software examples may target Arduino, ESP32, STM32,
FPGA and other platforms.
