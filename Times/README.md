# Times

Electronic timekeeping modules.

This category includes:

- Real-time clock modules (RTC)
- Timekeeping and calendar IC modules
- Time synchronization hardware
- Other electronic time-related modules

## Module catalog

Individual module directories are added when needed.

Each directory identifies the actual hardware board,
its revision and relevant technical characteristics.

## Practical use

Examples, libraries, connection diagrams and observations
are added according to real engineering needs.
