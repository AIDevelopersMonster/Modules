# DS3231SN + AT24C32 — Arduino UNO + PowerShell CLI

Проект для раздела `Modules/Times/DS3231`.
Arduino считывает и устанавливает время на DS3231, PowerShell управляет им по COM-порту.
**Время устанавливается автоматически из системных часов Windows**, без ручного ввода даты.

## Подключение

| Arduino UNO | DS3231-AT24C32 |
| --- | --- |
| A5 (SCL) | SCL |
| A4 (SDA) | SDA |
| 5V | VCC |
| GND | GND |

Используется четырёхконтактный разъём `SCL SDA VCC GND`. Выводы `SQW` и `32K` не подключаем.
EEPROM AT24C32 пока не используется. **Батарею CR2032 не ставить**, пока не установлено,
есть ли на этой плате цепь её зарядки. При отсутствии резервного питания время может сбиться
при отключении USB; снова выполнить синхронизацию.

## Установка

1. Открыть `DS3231_UNO_Time_Serial.ino` в Arduino IDE и загрузить в UNO (один раз).
   Если предыдущий скетч уже загружен, повторная прошивка не нужна.
2. **Закрыть Serial Monitor и Serial Plotter** — один COM-порт нельзя открыть одновременно
   в двух программах.
3. В PowerShell перейти в папку со скриптом и выполнить команды ниже.

## Команды PowerShell

```powershell
Set-Location C:\GitHub\Modules\Times\DS3231\ArduinoUNO

.\rtc.ps1 Ports                 # Показать доступные COM-порты
.\rtc.ps1 Sync COM4             # Записать в RTC текущее локальное время Windows
.\rtc.ps1 Read COM4             # Прочитать время с RTC
.\rtc.ps1 Monitor COM4          # Потоковое чтение, остановка Ctrl+C
.\rtc.ps1 Sync COM4 -Utc        # Альтернативно: установить время UTC
```

`COM4` — **пример**, подставить фактический порт Arduino.
При `Sync` скрипт открывает COM-порт на 9600 бод, ждёт примерно 2,5 с после
возможного автоматического сброса UNO, считывает текущее время ПК,
отправляет `SET YYYY-MM-DD HH:MM:SS` и ждёт подтверждения Arduino.

**Время RTC хранится без часового пояса**. По умолчанию используется локальное
время Windows на этом ПК; если проект предполагает UTC, использовать `-Utc`
последовательно. Системные часы ПК должны быть корректно настроены.
Точность установки рассчитана на прикладные задачи порядка секунды;
это не NTP/PPS-измеритель и не калибровка кварца.

При `Read` скрипт только считывает время и **ничего не устанавливает**.

## Пример ответа

```text
PS> .\rtc.ps1 Sync COM4
Sending Windows local time to COM4 : 2026-10-18 12:34:56
RTC accepted the new date/time.
RTC readback: 2026-10-18 12:34:56

PS> .\rtc.ps1 Read COM4
RTC: 2026-10-18 12:35:02
```

## Возможные сообщения

- `No SET confirmation` — неверный порт, не та прошивка или отсутствие ответа.
- `ERROR: DS3231 not responding at 0x68` — проверить питание и подключение I2C.
- `WARNING: OSF=1` — микросхема сообщила о возможной остановке генератора;
  такой результат чтения до синхронизации может быть недостоверным.
- `Access denied` — COM-порт уже открыт другой программой.

Прошивка использует только встроенную `Wire.h`, команды `READ` и `SET`.
Проверка предельной частоты опроса для практической задачи не требуется.
